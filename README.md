# FOSSEE Workshop Booking Portal – UI/UX Enhancement

## 🚀 Overview

This project focuses on enhancing the **user interface and user experience** of the FOSSEE Workshop Booking Portal.

The goal was to modernize the frontend while keeping the existing Django backend intact, improving usability, clarity, and visual hierarchy.

---

## 🎯 Objectives

- Improve overall UI aesthetics
- Enhance user experience and navigation
- Make layouts more responsive and intuitive
- Introduce modern design patterns
- Ensure better readability and interaction feedback

---

## ✨ Key Improvements

### 🔹 Dashboard Redesign
- Clean and structured layout with sidebar + main content
- Added filter panel with proper labeling
- Introduced summary cards (Total, Upcoming, Completed workshops)
- Improved table UI with:
  - Status badges (color-coded)
  - Hover effects
  - Search bar
  - Empty state handling
- Sticky sidebar for better usability

---

### 🔹 Login Page Enhancement
- Centered card-based layout
- Improved input fields with focus states
- Added branding (FOSSEE)
- Clear call-to-action (Login)
- Added "Forgot Password" for UX completeness

---

### 🔹 Registration Page
- Designed consistent with login UI
- Added multiple input fields (Name, Email, Password)
- Smooth navigation between login and register
- Maintained visual consistency across pages

---

## 🧠 UX Improvements

- Better spacing and layout alignment
- Visual hierarchy using typography and colors
- Interactive elements (hover, focus states)
- Responsive design for different screen sizes
- Improved readability and accessibility

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Backend (existing):** Django

## ⚙️ How to Run

### 1. Clone the repository
```bash
git clone <your-repo-link>
cd workshop_booking
```

### 2.Run backend (Django)
```bash 
python manage.py runserver
```

### Run frontend
```bash
cd frontend
npm install
npm start
```

💡 Notes
This project focuses on UI/UX improvements only
Backend logic and functionality remain unchanged
The frontend is built separately and can be integrated with Django APIs
